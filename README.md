# 🐶 Dog Breed Classifier – Identify Your Pup with AI

Welcome to the **Dog Breed Classifier** – a deep learning-based image classification system that identifies the breed of a dog from an image. Whether you’re a dog lover, veterinarian, or AI enthusiast, this project demonstrates how convolutional neural networks (CNNs) and transfer learning can be used to solve real-life image recognition problems with high accuracy.

---
## 📦 Dataset

This classifier is trained on the **Stanford Dogs Dataset**, containing over **10,000 images** across **120 dog breeds**. Each image has been carefully annotated and preprocessed to ensure high-quality training data.

---
## 🚀 Why This Project Stands Out

While many classifiers exist online, here’s what makes this one **special**:

### ✅ End-to-End Architecture
- Custom-trained CNN with fine-tuned feature extractor using **TensorFlow Hub**.

### 🧠 Model Highlights
- Uses **Transfer Learning** with pre-trained feature extractor (`mobilenet_v2` or `efficientnet`).
- Classifies among multiple popular dog breeds (e.g., Golden Retriever, Pug, German Shepherd).
- Handles noisy images and real-world photo variations.

---

## 🌐 Web App Interface

- Built with **Flask** for backend routing.
- Clean, responsive **HTML/CSS** frontend for uploading images and viewing predictions using ClaudeAI.
- Displays predicted breed along with **confidence score**.

---

## 🛠 Tech Stack

- 🐍 **Python** – Core logic and backend
- 🧠 **TensorFlow/Keras** – Deep learning and CNN
- 📦 **TensorFlow Hub** – Pretrained models
- 🖼️ **OpenCV / PIL** – Image preprocessing
- 🌐 **Flask** – Web application
- 🎨 **HTML + CSS** – Frontend design

| Feature | Description |
